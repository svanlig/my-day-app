MY DAY — COMPLETE V3

Features:
Today: current task, scheduled tasks, task descriptions, daily notes, Daily Pursuits, today's Personal Challenges.
Schedule: add/edit/delete tasks, start/end times, daily recurrence, descriptions.
Daily Pursuits: separate productivity list, daily completion and notes.
Personal Challenges: name, description, start/end dates, optional daily target, daily check-ins, comments, progress, completed list, final accomplishment.
History: browse by date or previous/next day; task, pursuit and challenge completion/notes.
Design: black and white, Rubik.
Storage: browser localStorage.
Sound/reminders: intentionally not added/changed yet.

RUN:
1. Extract the ZIP.
2. Open the extracted folder.
3. In File Explorer address bar type cmd and press Enter.
4. Type: py -m http.server 8000
5. Open http://localhost:8000 in Chrome.

Your data stays in this browser's local storage. Do not clear the site's browser data if you want to keep it.
